# Thornwake two-PC playtest, November 19

## Before starting

Extract the same build on both Windows computers. Put the MSI and PowerSpec on the same private LAN. Note which PC hosts, the build checksum, resolution and whether either PC uses Wi-Fi. Record any network address only in your local connection dialog. Use the launch instructions included in the ZIP.

## Ten-minute paired check

| Step | What to observe on both monitors | Result |
|---|---|---|
| Host on MSI, join on PowerSpec | Both reach the same frontier. Each camera follows its own controllable Wayfarer. | Pending |
| Walk in opposite directions, stop, then cross paths | Both explorers move on both screens. Neither continues sliding after the keys are released. | Pending |
| Collect a survey marker as guest | The objective updates on both clients and the marker can only be collected once. | Pending |
| Take the northern gate together | Both see the same dungeon and their companion. Confirm input resumes after arrival. | Pending |
| Fight the Stone Watch together | Keep both players in view. Alternate F strikes. Compare guardian health after every strike and defeat on both screens. | Pending |
| Stand in one warning and dodge another | Compare damage, health and recovery on both screens. Note which player was inside the ring. | Pending |
| Return, then close the guest | The host remains controllable. Try to join again and record whether this is a fresh explorer or a restored session. | Pending |
| Reverse host and guest | Create a fresh session on PowerSpec and join from MSI. | Pending |

For a defect, note build, step, host or guest, expected outcome and what each monitor showed. For a freeze, note whether the other PC kept moving. Capture a short clip from both monitors where possible.
