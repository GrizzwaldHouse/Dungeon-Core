# Zero-credit character pack review

Generated on November 1, 2026 with Blender 5.1.2 using `tools/blender/build_runtime_character_pack.py`. The seven GLB candidates and 35 review views are here. `asset-manifest.json` records every file's SHA-256, size, triangle count before modifiers, mesh and material counts, and animation inventory. The source is procedural geometry authored for this project. Meshy was not used and no credits were spent.

This is a reproducible technical and silhouette study, not approved production art. The visible renders are faceted and flat. The Wayfarers have class equipment but lack the repaired cloth and surface detail of the approved cover. The Deepwood Sentinel reads as a horned trunk but lacks convincing root mass and bark layering. The Rootling reads as a spiked ground creature more than a root. The Barkwing has separated wings, a body above its talons, and a small violet accent, but its panels remain too geometric. In particular, the angled wing shape needs torn edges and a distinct branch skeleton. These findings prevent a 95/100 visual claim. No independent jury score was run for this pack.

Every asset lacks a skeletal rig and combat clips. Only the Barkwing contains a rigid wing preview across frames 1 to 13. Triangle counts exclude solidify modifiers and may differ from exported triangle counts. The low polygon counts and small GLB sizes indicate a plausible mobile starting point, but no browser frame-time, memory, loading, or physical-phone checks have been run. The files have not been imported into `client/render.js` or copied into the served `client/assets/models` path. The existing game visuals remain the runtime version.

Review order: compare all five views for the Barkwing and Sentinel against `client/title-cover-deepwood.png`; approve or reject each silhouette; refine bark, roots, torn wings, cloth, and role equipment; create full rigs and action clips; then test imported GLBs on desktop and a physical phone. Promote a single reviewed slot only after the 95/100 visual jury and performance gates in `docs/design/POST_SUBMISSION_3D_ASSET_INTEGRATION_PLAN.md` pass.
